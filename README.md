HealthIQ Predictor

This project was developed as part of a technical assessment to build a health prediction application using patient blood test data.

The application stores and manages patient records including name, date of birth, email address, glucose level, haemoglobin level and cholesterol level. Based on the entered values, the system generates health-related remarks and risk insights.

The application supports:

- Creating new patient records
- Viewing existing records
- Updating patient information
- Deleting records
- Downloading records and reports
- Validating user inputs before saving data

Patient information is stored using SQLite, allowing records to persist between sessions.

The application was developed using Python and Streamlit with a focus on simplicity, usability and maintainable code structure.
